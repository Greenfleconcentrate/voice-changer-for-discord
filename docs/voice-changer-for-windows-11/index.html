Voice changer for Windows 11

Use this free voice changer on Windows 11 or Windows 10. Pick it in one app, or make it the default microphone for your whole PC.

Download from SourceForge

Set it as your default microphone

  1. Download Voice Changer and choose a voice model.
  2. Open Settings, then System, then Sound. The path is the same on Windows 11 and Windows 10.
  3. In the Input section, select Voice Changer.

Apps that follow the Windows default will now use your changed voice. Select your usual microphone on the same page to change back.

Use it in one app only

Keep your normal microphone as the Windows default and select Voice Changer inside the app you want, such as Discord or Zoom. Every other app keeps your own voice.

Voice changer software for Windows, built to run locally

This voice changer software for Windows can run everything on your PC. You can also offload the processing to another machine when you need the power for games.
