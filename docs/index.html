Voice changer questions

Is this voice changer really free?

Yes. It is a free, open source voice changer. You can download it from SourceForge and read the source code on GitHub.

Is this an open source AI voice changer?

Yes. The app and its source code are public, so developers can check how the real time voice changer works and build on it.

Does it process my voice locally?

It can. Run everything on your own computer, or send the processing to another machine that you choose.

Can I use it as a voice changer for Discord?

Yes. In Discord, open User Settings, then Voice & Video, and choose it as your Input Device.

Which systems does the voice changer run on?

Windows, Mac (M1) and Linux.

Can I use RVC voice models?

Yes. It works as an RVC AI voice changer, and you can import your own voice models as well as use popular ones.

What if a game starts to lag?

AI voice conversion takes computing power. Offload the processing to another machine so the game keeps running smoothly on your PC.

Where do I get the voice changer download?
